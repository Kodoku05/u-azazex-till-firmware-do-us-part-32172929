A one-sentence wedding vow spoken by a robot: calling its spouse its favorite bug and promising never to fix it supplies the situational joke, while refusing replacement carries tenderness. Updates, crashes, newer models, bugs, and fixes give the vow its machine voice.

## Run it

```sh
node main.ts
```

Writes the vow (129 characters / 131 bytes, no trailing newline) to `/output/entry.txt`. Uses only the Node 22 standard library, with no network or secrets, and is deterministic.
